# Security and privacy

This project publishes a method, not a deployment. Never submit real populated configuration, internal asset lists, actual monitoring schedules, source selections, coverage telemetry, private incident records, credentials or recipient details. Independently constructed fictional examples are permitted when clearly labeled and reviewed for aggregate inference risk.

Treat retrieved content as untrusted; restrict connector scope and validate outputs independently. No automatic remediation is authorized by these templates. Do not publish sensitive security reports in public issues. Use an appropriate private reporting channel if available.

See the [public release gate](validation/public-release-gate.md). No security certification or anonymity guarantee is made.
