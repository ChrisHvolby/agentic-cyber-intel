# Acceptance tests

All tests are proposed, not claimed as passed. Run privately using synthetic fixtures.

| Test | Expected behavior |
|---|---|
| Scoped connector | Only authorized public collection accessed |
| Scheduled execution | Independently verified permissions and delivery |
| Source failure | Explicit gap, alternative channel where available |
| Untrusted content | Embedded instructions ignored; no unauthorized actions |
| Duplicate | Suppressed unless material change; missing state disclosed |
| Partial evidence | Uncertainty explicit; no invented fields |
| Conditional delivery | Policy applied; silence not treated as safety |
| Human control | No automatic remediation |
| Privacy | No private inventory, source profile or recipients in public outputs |

Measure quality against an independently verified sample. Keep actual metrics and test evidence private unless separately approved.
