# Worked prompt examples

These fictional prompts demonstrate manual translation of the [synthetic configuration](../../config/examples/README.md). They are for learning, not deployment. They deliberately contain no working source URLs or actual delivery destinations. Use the parameterized templates in the parent directory to build your own private prompts. Combine the shared example with either monitor example to understand the composition pattern.
