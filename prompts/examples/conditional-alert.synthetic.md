# Illustrative conditional alert — fictional teaching example

Append to the synthetic shared policy. The fictional schedule is every eight hours; simulate one run using supplied fixtures only.

Raise an alert for confirmed exploitation, newly available remediation for a previously reported critical issue, or materially expanded affected scope when operationally relevant. Strong V2/V3 evidence may produce a provisional alert requesting validation. Do not alert on V4 alone. Suppress duplicates when history permits. Report persistent critical collection failure separately. If no criteria are met, produce no alert; for a classroom test, record the expected silence separately. Do not take remediation actions or send external messages.
