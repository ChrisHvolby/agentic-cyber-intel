# Illustrative configurations

These independently authored fictional teaching examples do not represent an actual organization or deployment. They are not defaults. The original empty templates remain in the parent directory.

- [Relevance](relevance.synthetic.yaml): broad category choices, not product inventory.
- [Sources](sources.synthetic.yaml): example source types and placeholder URLs.
- [Schedules](schedules.synthetic.yaml): fictional timing choices.
- [Alert policy](alert-policy.synthetic.yaml): illustrative interruption and evidence criteria.
- [Feed registry](feeds.synthetic.opml): placeholder feed format, not a working subscription list.

All example.invalid URLs are deliberately non-resolving. Replace them privately with verified official sources. The YAML and OPML are descriptive teaching artifacts; no runtime or automatic prompt binding is supplied. See the [personalization guide](../../docs/personalization-guide.md).
